## Description

カレンダーの表示月を変更する操作は前月・次月ボタンに限られており、年月を直接選択するモーダルがありません。遠い年月へ移動する場合に何度も月移動ボタンを押す必要があるため、年月を直接指定できる操作を追加し、日付選択の利便性を高めたいという要望です。

---

## Steps to Reproduce（確認手順）

1. 勤怠管理システムのカレンダーを表示する。
2. 年月表示と前月・次月ボタンを確認する。
3. 年月を直接選択する操作がないことを確認する。

---

## Expected Behavior（期待される動作）

年月選択モーダルから年と月を指定し、該当月のカレンダーへ移動できること。年をまたぐ移動にも対応し、既存の前月・次月ボタンも引き続き利用できること。

---

## Actual Behavior（実際の動作）

年月は見出しに表示されますが、表示月の変更は前月・次月ボタンに限られています。

# Resolution Log（解決記録）

## Investigation（調査内容）

1. REQ-UC002とカレンダー画面設計に、年月の直接選択が定義されていないことを確認。
2. `frontend/src/components/Calendar.tsx` では年月見出しと前月・次月ボタンが実装されているが、年月選択モーダルはないことを確認。
3. UC002のE2Eシナリオに、年月の直接選択やキャンセル動作を確認するケースがないことを確認。
4. 既存Issue一覧を確認し、本件に該当するIssueがないことを確認。ISS-003、ISS-007、ISS-009は別の事象である。

## Root Cause（原因）

カレンダー要件は日付選択と月移動を中心に定義され、年月を直接指定する操作が要件化されていません。

## Solution Applied（実施した対応）

REQ-UC002、画面設計、シーケンス図に年月選択の仕様を定義し、年・月選択、確定、キャンセル、Escapeキー、フォーカス復帰に対応するモーダルを実装した。E2Eシナリオを追加し、年の境界値、確定、キャンセル、Escapeキーを含む動作を確認した。
