## Description

勤務時間入力・休暇登録・削除確認のダイアログで、Escapeキーによる閉じる／キャンセル操作や、ダイアログ表示中のフォーカス管理が実装されていない。キーボードや支援技術を利用するユーザーが、ダイアログを完了または安全に閉じにくい。

---

## Steps to Reproduce（バグの場合）

Category = Enhancement のため記載なし。

---

## Expected Behavior（期待される動作）

ダイアログを開いたときにフォーカスがダイアログ内へ移動し、表示中は適切に制御される。閉じると起動元へフォーカスが戻る。Escapeキーでは最前面のダイアログを閉じる、または確認画面をキャンセルできる。

---

## Actual Behavior（実際の動作）

各ダイアログに `aria-modal="true"` は設定されているが、Escapeキーの処理や表示・終了時のフォーカス移動、ダイアログ内へのフォーカス制限が見当たらない。

## Proposed Solution（提案対応）

1. 勤務時間入力、休暇登録、削除確認のダイアログでEscapeキー操作を定義する。
2. ダイアログ表示時・終了時のフォーカス移動と、表示中のフォーカス制御を実装する。
3. キーボードのみで開く・操作する・閉じる一連の動作を確認するUIテストを追加する。
