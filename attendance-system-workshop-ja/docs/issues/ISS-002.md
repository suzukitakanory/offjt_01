## Proposed Solution（提案対応）

## Investigation（調査内容）

1. `frontend/src/components/WorkTimeForm.tsx` を確認した。
2. 背景要素にクリック処理はなく、`onClose` は×ボタンとキャンセルボタンからのみ呼び出されている。
3. E2Eシナリオには背景クリック時に閉じること、およびダイアログ内部クリックでは閉じないことの検証がない。
4. `docs/design/screen-design.md` と `docs/design/domain/sequence/SEQ-REQ-UC003-勤務時間入力.md` のダイアログ操作仕様を確認した。

---

## Root Cause（原因）

背景要素にクリックイベント処理が実装されていないため、ダイアログ外をクリックしても閉じない。設計書とE2Eシナリオにも背景クリック時の動作が定義されていない。

---

## Solution Applied（実施した対応）

`WorkTimeForm` の背景要素でクリックイベントの対象が背景自身の場合のみ `onClose` を呼び出すようにした。ダイアログ内部クリックでは閉じない。背景クリック時にダイアログが閉じ、保存成功メッセージが表示されないことを確認するE2Eシナリオを追加した。

Docs unchanged: 要件定義、API仕様、データベース設計は変更せず。操作上の振る舞いのみの追加で、API・データ形式に影響しないため。
