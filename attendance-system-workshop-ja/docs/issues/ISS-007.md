## Description

現在のカレンダーには日付と曜日が表示されますが、祝日の日付や名称は表示されません。祝日をカレンダー上で識別できるようにし、勤怠操作時に日付の性質を把握しやすくしたいという要望です。

起票時点では対象地域、表示する祝日の範囲、祝日データの取得元は未確定でした。現在の決定事項は本IssueのNotesおよび祝日データ仕様書を参照してください。

---

## Expected Behavior（期待される動作）

対象とする祝日の日付がカレンダー上で通常の日付と区別でき、必要に応じて祝日名も確認できること。表示対象とデータの提供方法は要件確認時に決定する。

---

## Actual Behavior（実際の動作）

カレンダーには日付番号と曜日が表示されますが、祝日の日付を判定または表示する処理はありません。

## Proposed Solution（提案対応）

1. 内閣府「国民の祝日」CSVをデータソースとし、日本の法律に基づく国民の祝日、振替休日および国民の休日を対象とする。自治体・企業独自の休日は対象外とする。
2. 公式CSVをUTF-8へ変換してフロントエンドに同梱し、実行時は外部接続せず、カレンダーの日付セルに祝日名を表示する。
3. CSV収録期間外の日付は祝日判定できないことを画面上で案内し、対象外日を非祝日と誤認させない。
4. CSV更新時のデータ検証・レビュー手順を定め、祝日・非祝日・収録期間外・年またぎの表示テストを追加する。

## Investigation（調査内容）

1. 祝日表示前のREQ-UC002には祝日の受け入れ基準がなく、`Calendar.tsx`にも祝日データの参照・表示処理がありませんでした。
2. 添付された内閣府CSVの文字コード・ヘッダー・日付順・重複・収録範囲を確認しました。CSVはShift-JIS、1,067件、1955-01-01～2027-11-23で、日付重複はありませんでした。
3. 既存の年月選択モーダルの実装を維持したまま、カレンダーセルへ祝日名を追加できることを確認しました。

---

## Root Cause（原因）

祝日表示が要件・受け入れ基準に定義されておらず、祝日データとカレンダー表示を連携する機能が実装されていませんでした。

---

## Solution Applied（実施した対応）

1. 内閣府CSVをUTF-8へ変換してフロントエンドに同梱し、実行時の外部接続を不要にしました。
2. CSVデータのヘッダー、列数、日付形式・実在性、名称、重複、昇順を検証する処理を追加しました。
3. 祝日セルに「祝」マークと公式CSV記載の名称を表示し、読み上げ用ラベルも追加しました。
4. カレンダーグリッドにCSV収録期間外の日付がある場合の案内を追加し、期間外日付を祝日・非祝日と誤認しないようにしました。
5. 既存の年月選択モーダルを維持し、祝日表示と同時に動作することをE2Eで確認しました。
