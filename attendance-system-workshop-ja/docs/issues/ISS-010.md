## Description

休暇登録入力ダイアログで、ダイアログ外の背景をクリックしてダイアログを閉じられるようにしたい。勤務時間入力ダイアログではISS-002で同様の操作が追加されたが、休暇登録ダイアログには実装されていない。

---

## Steps to Reproduce（確認手順）

1. カレンダーで任意の日付を選択する。
2. 「休暇登録」を選択して休暇登録ダイアログを開く。
3. ダイアログ外の背景をクリックする。
4. ダイアログが閉じないことを確認する。

---

## Expected Behavior（期待される動作）

休暇登録ダイアログの外側の背景をクリックすると、保存せずダイアログが閉じる。ダイアログ内部のクリックでは閉じず、×ボタンとキャンセルボタンの既存動作も維持する。

---

## Actual Behavior（実際の動作）

ダイアログ外の背景をクリックしても閉じない。現在は×ボタンまたはキャンセルボタンで閉じる必要がある。

## Proposed Solution（提案対応）

1. `LeaveForm` の外側背景で、クリック対象が背景自身の場合のみ `onClose` を呼び出す。
2. ダイアログ内部や削除確認ダイアログの操作では、休暇登録ダイアログが意図せず閉じないようにする。
3. 背景クリックで閉じること、内部クリックでは維持されることを確認するE2Eシナリオを追加する。

# Resolution Log（解決記録）

## Investigation（調査内容）

1. `frontend/src/components/LeaveForm.tsx` を確認した。
2. `.leave-modal-backdrop` にクリック処理はなく、`onClose` は×ボタンとキャンセルボタンからのみ呼び出されている。
3. UC004のE2Eシナリオに、背景クリックによる終了動作の検証がないことを確認した。
4. ISS-002は `WorkTimeForm` の背景クリック対応であり、`LeaveForm` には同様の処理がないことを確認した。

## Root Cause（原因）

休暇登録ダイアログの背景要素にクリックイベント処理が実装されていないため、画面外をクリックしても閉じない。
