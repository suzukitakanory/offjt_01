# 祝日データ仕様書

## 1. 目的

内閣府が公開する「国民の祝日」CSVを用いて、日本の法律に基づく祝日をカレンダーに表示するためのデータ取扱いを定義します。

## 2. データソース

- **提供元**: 内閣府
- **公式案内**: https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html
- **CSV**: https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv
- **対象**: 「国民の祝日に関する法律」に定める国民の祝日、振替休日および国民の休日
- **対象外**: 地方公共団体等および企業が独自に定める休日・記念日

## 3. 配布・利用方式

- 公式CSVを取得し、フロントエンドで扱えるUTF-8データに変換してアプリケーションに同梱します。
- 実行時に内閣府サイトへ接続せず、カレンダーは同梱データを参照します。祝日表示用のAPIやデータベーステーブルは追加しません。
- データは日付と祝日名を保持し、日付はアプリケーション内で`YYYY-MM-DD`形式として扱います。
- CSVの名称はそのまま表示します。「休日」等の名称を「振替休日」と推測して置換しません。

## 4. 更新・検証

1. 内閣府の公式案内から最新CSVを取得します。
2. 公式CSVの列構造・文字コードを確認し、UTF-8へ変換します。
3. ヘッダー、日付の書式と実在性、祝日名の空欄、日付の重複および昇順を検証します。
4. 収録期間、既知の祝日・休日を確認し、変換データをレビュー可能な変更としてリポジトリに反映します。
5. データ更新後、フロントエンドbuild/lintおよび祝日表示E2Eシナリオを実行します。

更新頻度は、内閣府が翌年以降の祝日を公開した時点および公式データの変更時とします。

## 5. 収録期間外の扱い

- 判定可能な期間は、同梱CSVに含まれる最初の日付から最後の日付までとします。
- 収録期間内の日付は、CSVに日付がある場合に祝日として表示し、ない場合は祝日表示を行いません。
- 収録期間外の日付は祝日・非祝日のいずれとも判定しません。
- 表示中のカレンダーグリッドに収録期間外の日付がある場合、「一部の日付は祝日データの対象外です。」と案内し、対象外日を非祝日と誤認させないようにします。
