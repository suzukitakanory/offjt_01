# メッセージ定義書

システムで使用するすべてのメッセージを一元管理します。

## 命名規則

### メッセージID

* **エラーメッセージ**: `ERR{カテゴリ2桁}{連番3桁}` (例: `ERR01001`)
* **成功メッセージ**: `SUCCESS{カテゴリ2桁}{連番3桁}` (例: `SUCCESS01001`)
* **情報メッセージ**: `INFO{カテゴリ2桁}{連番3桁}` (例: `INFO01001`)
* **警告メッセージ**: `WARN{カテゴリ2桁}{連番3桁}` (例: `WARN01001`)
* **カテゴリ番号**: 機能グループごとに割り当て

## カテゴリ一覧

| カテゴリ | カテゴリ名     | 説明                         |
| -------- | -------------- | ---------------------------- |
| 01       | システム       | システム起動・ヘルスチェック |
| 02       | 勤怠管理       | 勤務時間入力・休暇登録       |
| 03       | バリデーション | 入力値検証                   |
| 99       | 共通           | 共通メッセージ               |

### カテゴリ01: システム

#### REQ-UC001: システム起動

| メッセージID | メッセージ内容                                                       | 説明                     | 関連画面 | 関連要件  |
| ------------ | -------------------------------------------------------------------- | ------------------------ | -------- | --------- |
| INFO01001    | システムを起動しています...                                          | システム起動中の情報表示 | SCR-001  | REQ-UC001 |
| ERR01001     | システムに接続できませんでした。しばらくしてから再度お試しください。 | システム接続エラー       | SCR-001  | REQ-UC001 |
| ERR01002     | システムが一時的に利用できません。                                   | システムメンテナンス中   | -        | REQ-UC001 |

#### REQ-UC002: カレンダー操作

| メッセージID | メッセージ内容                  | 説明                                         | 関連画面 | 関連要件  |
| ------------ | ------------------------------- | -------------------------------------------- | -------- | --------- |
| INFO01003    | カレンダーを読み込んでいます... | カレンダー初期表示時の情報表示（オプション） | SCR-001  | REQ-UC002 |

**備考**: REQ-UC002（カレンダー操作）は、フロントエンド側の状態管理のみで実現されるため、エラーメッセージは発生しません。日付選択や月切り替えは即座に実行され、ユーザーへのフィードバックは視覚的な変更（ハイライト、カレンダー更新）で行われます。

## メッセージ詳細定義

### INFO01001: システムを起動しています...

- **メッセージタイプ**: INFO（情報）
- **カテゴリ名**: システム
- **表示条件**: システム起動時、メイン画面のロード中
- **ユーザーの対処方法**: なし（待機）
- **関連画面**: SCR-001（メイン画面）
- **関連要件**: REQ-UC001
- **HTTPステータスコード**: -（フロントエンド表示のみ）

### ERR01001: システムに接続できませんでした。しばらくしてから再度お試しください。

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: システム
- **表示条件**: システムURLにアクセスしたが、バックエンドAPIに接続できない場合
- **ユーザーの対処方法**: しばらく待ってから再度アクセスする、またはシステム管理者に連絡
- **関連画面**: SCR-001（メイン画面）
- **関連要件**: REQ-UC001
- **HTTPステータスコード**: -（接続エラーのため）

### ERR01002: システムが一時的に利用できません。

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: システム
- **表示条件**: システムメンテナンス中またはヘルスチェックで「DOWN」が返された場合
- **ユーザーの対処方法**: メンテナンス終了まで待機
- **関連画面**: -
- **関連要件**: REQ-UC001
- **HTTPステータスコード**: 503

### INFO01003: カレンダーを読み込んでいます...

- **メッセージタイプ**: INFO（情報）
- **カテゴリ名**: システム
- **表示条件**: カレンダー初期表示時（オプション）。通常は即座に表示されるため、このメッセージは表示されない
- **ユーザーの対処方法**: なし（待機）
- **関連画面**: SCR-001（メイン画面）
- **関連要件**: REQ-UC002
- **HTTPステータスコード**: -（フロントエンド表示のみ）
- **備考**: REQ-UC002の実装では、カレンダーはフロントエンド側で即座に生成されるため、通常このメッセージは不要。将来的にバックエンドから勤怠データを取得する場合にのみ使用される可能性がある

### ERR99001: 予期しないエラーが発生しました。システム管理者に連絡してください。

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: 共通
- **表示条件**: 予期しない例外が発生した場合（catch-allエラー）
- **ユーザーの対処方法**: システム管理者に連絡し、エラー発生時刻と操作内容を報告
- **関連画面**: 全画面
- **関連要件**: 全要件
- **HTTPステータスコード**: 500

### ERR99002: ネットワークエラーが発生しました。接続を確認してください。

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: 共通
- **表示条件**: ネットワーク接続が切断された、またはタイムアウトした場合
- **ユーザーの対処方法**: ネットワーク接続を確認し、再度操作を実行
- **関連画面**: 全画面
- **関連要件**: 全要件
- **HTTPステータスコード**: -（ネットワークエラーのため）

### SUCCESS02001: 勤怠情報が正常に保存されました

- **メッセージタイプ**: SUCCESS（成功）
- **カテゴリ名**: 勤怠管理
- **表示条件**: 勤務時間または休暇の登録・更新が正常に完了した場合
- **ユーザーの対処方法**: なし
- **関連画面**: SCR-002（勤務時間入力フォーム）、SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC003, REQ-UC004
- **HTTPステータスコード**: -（API成功レスポンスを受けた後にフロントエンドで表示）

### SUCCESS02002: 休暇情報が正常に削除されました

- **メッセージタイプ**: SUCCESS（成功）
- **カテゴリ名**: 勤怠管理
- **表示条件**: 休暇削除APIが`204 No Content`を返した場合
- **ユーザーの対処方法**: なし
- **関連画面**: SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: -（API成功レスポンスを受けた後にフロントエンドで表示）

### ERR02001: 指定日には休暇登録の対象外となる勤怠レコードが存在します

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: 勤怠管理
- **表示条件**: 休暇登録・更新・削除の対象日に、`WORK`またはUC004対象外の勤怠ステータスのレコードが存在する場合
- **ユーザーの対処方法**: 既存の勤怠レコードを確認し、対象日や操作内容を見直す
- **関連画面**: SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: 409

### ERR02002: 指定された日付の休暇レコードが見つかりません

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: 勤怠管理
- **表示条件**: 休暇削除APIの対象日・従業員に一致する休暇レコードが存在しない場合
- **ユーザーの対処方法**: 画面を再読み込みして対象日の登録状態を確認する
- **関連画面**: SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: 404

### ERR03001: 出勤時刻は退勤時刻より前である必要があります

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 出勤時刻が退勤時刻と同じか、それより後の場合
- **ユーザーの対処方法**: 出勤時刻が退勤時刻より前になるように入力する
- **関連画面**: SCR-002（勤務時間入力フォーム）
- **関連要件**: REQ-UC003
- **HTTPステータスコード**: 400（API側の検証時。フロントエンド側の検証時はHTTP通信なし）

### ERR03002: 有効な時刻形式で入力してください

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 出勤時刻または退勤時刻が有効なHH:MM形式でない場合
- **ユーザーの対処方法**: 00:00～23:59の範囲でHH:MM形式を入力する
- **関連画面**: SCR-002（勤務時間入力フォーム）
- **関連要件**: REQ-UC003
- **HTTPステータスコード**: 400（API側の検証時。フロントエンド側の検証時はHTTP通信なし）

### ERR03003: 従業員IDの形式が不正です

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 従業員IDが `EMP` に続く3桁の数字ではない場合
- **ユーザーの対処方法**: 正しい従業員IDを指定する
- **関連画面**: SCR-002（勤務時間入力フォーム）、SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC003, REQ-UC004
- **HTTPステータスコード**: 400

### ERR03004: 有効な日付をYYYY-MM-DD形式で指定してください

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 勤怠日が有効な日付ではない、または `YYYY-MM-DD` 形式ではない場合
- **ユーザーの対処方法**: 選択した日付を確認する。未来日付は許可される
- **関連画面**: SCR-002（勤務時間入力フォーム）、SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC003, REQ-UC004
- **HTTPステータスコード**: 400

### ERR03005: 出勤時刻と退勤時刻を入力してください

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 勤務ステータスが `WORK` で、出勤時刻または退勤時刻が未指定の場合
- **ユーザーの対処方法**: 出勤時刻と退勤時刻の両方を入力する
- **関連画面**: SCR-002（勤務時間入力フォーム）
- **関連要件**: REQ-UC003
- **HTTPステータスコード**: 400

### ERR03006: 勤怠ステータスが不正です

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 勤怠ステータスが定義された値ではない場合
- **ユーザーの対処方法**: 定義された勤怠ステータスを指定する
- **関連画面**: SCR-002（勤務時間入力フォーム）、SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC003, REQ-UC004
- **HTTPステータスコード**: 400

### ERR03007: 休暇の場合、出退勤時刻は指定できません

- **メッセージタイプ**: ERROR（エラー）
- **カテゴリ名**: バリデーション
- **表示条件**: 休暇ステータスで登録・更新するリクエストに出勤時刻または退勤時刻が指定された場合
- **ユーザーの対処方法**: 出退勤時刻を指定せず、休暇区分と必要に応じてメモを入力する
- **関連画面**: SCR-003（休暇登録フォーム）
- **関連要件**: REQ-UC004
- **HTTPステータスコード**: 400
