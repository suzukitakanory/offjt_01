## 命名規則

### シーケンス図ID

- **形式**: `SEQ-{連番3桁}` (例: `SEQ-001`)
- **命名規則**: フローの目的が明確になるように命名

## シーケンス図詳細

### SEQ-UC002-005: 祝日データの読み込みと表示

#### 目的

* 同梱された内閣府「国民の祝日」CSVに基づき、カレンダーの日付セルに祝日名を表示する
* CSVの収録期間外の日付を祝日・非祝日と誤認させない

#### 範囲

* **トリガー**: カレンダーの初期表示、または表示月の切り替え
* **含むコンポーネント**: カレンダーコンポーネント、同梱祝日データ、SCR-001
* **除外**: 実行時の内閣府サイトへのアクセス、祝日データAPI、データベース保存

#### 前提条件

* フロントエンドに内閣府CSVをUTF-8へ変換した祝日データが同梱されている
* データは日付・祝日名および収録期間を判定できる状態で管理される

#### 事後条件

* 収録期間内の日付に祝日データがある場合、日付セルに「祝」と祝日名が表示される
* 収録期間外の日付は祝日・非祝日のいずれとも扱われない
* カレンダーグリッドに収録期間外の日付がある場合、対象外期間の案内が表示される
* 祝日表示は日付選択や勤怠操作に影響しない

#### 基本フロー

1. カレンダーコンポーネントが初期化される、または従業員が表示月を切り替える
2. カレンダーコンポーネントが同梱祝日データを参照する
3. コンポーネントが表示中のカレンダーグリッドの日付ごとに祝日データと収録期間を照合する
4. 収録期間内で日付に該当する祝日があれば「祝」と祝日名を日付セルに表示する
5. グリッドに収録期間外の日付が含まれる場合、対象外の案内を表示する
6. 従業員が祝日表示を確認し、通常どおり日付を選択できる

#### 代替フロー

* **A1: 収録期間内でCSVに記録がない日付** — 通常の日付セルとして表示する
* **A2: 収録期間外の日付を含むカレンダー** — 収録期間内の日付は通常どおり判定し、期間外日付には祝日表示を行わず「一部の日付は祝日データの対象外です。」と案内する
* **A3: 同梱データの形式不正** — データ検証をbuild工程で検出し、無効な祝日データをリリースしない

#### シーケンス図

```mermaid
sequenceDiagram
    actor User as 従業員
    participant Calendar as カレンダーコンポーネント
    participant HolidayData as 同梱祝日データ
    participant UI as SCR-001表示

    User->>Calendar: カレンダーを表示または月を切り替え
    Calendar->>HolidayData: 日付・祝日名・収録期間を参照
    HolidayData-->>Calendar: 祝日データを返却
    Calendar->>Calendar: 表示グリッドの日付を照合
    Calendar->>UI: 祝日セルに「祝」と祝日名を表示
    opt グリッドに収録期間外の日付が含まれる
        Calendar->>UI: 対象外期間の案内を表示
    end
    UI-->>User: 祝日表示付きカレンダーを表示

    Note over User,HolidayData: 祝日データ参照時に実行時の外部通信は発生しない
```

### SEQ-UC002-001: カレンダー日付選択

#### 目的

* 従業員がカレンダーから任意の日付を選択し、その日付に対する操作オプションを表示する
* 選択した日付を視覚的にハイライト表示し、ユーザーに選択状態を明確に伝える

#### 範囲

* **トリガー**: 従業員がカレンダー上の日付セルをクリック
* **含むコンポーネント**: メイン画面（SCR-001）のカレンダーコンポーネント
* **除外**: 実際の勤怠データ取得（将来の要件で実装）、日付選択後の操作（UC003、UC004で実装）

#### 前提条件

* メイン画面（SCR-001）が表示されている
* カレンダーが正常にレンダリングされている
* 現在月のカレンダーが表示されている

#### 事後条件

* 選択した日付がハイライト表示される
* 選択日付に応じた操作オプションが表示される（「勤務時間入力」「休暇登録」ボタン等）
* システムの状態として、選択された日付が保持される

#### 基本フロー

1. 従業員がメイン画面（SCR-001）でカレンダーを閲覧している
2. 従業員がカレンダー上の任意の日付セルをクリックする
3. フロントエンド（React）が日付セルのクリックイベントを検知する
4. 選択された日付をコンポーネントのステート（state）に保存する
5. UIを更新し、選択された日付セルに視覚的なハイライト（背景色変更等）を適用する
6. 選択日付に応じた操作オプション（「勤務時間入力」「休暇登録」ボタン等）を表示する
7. 従業員が選択した日付と操作オプションを確認できる

#### 代替フロー

* **A1: 既に日付が選択されている状態で新しい日付を選択** — SEQ-UC002-003（カレンダー異なる日付選択）を参照
* **A2: 前月または翌月の日付セルをクリック** — 月が切り替わり、該当する日付が選択される（月切り替えとして扱う）

#### シーケンス図

```mermaid
sequenceDiagram
    actor User as 従業員
    participant Calendar as カレンダーコンポーネント
    participant State as Reactステート管理
    participant UI as UI表示
    
    User->>Calendar: 日付セルをクリック<br/>(例: 2025-01-15)
    activate Calendar
    Calendar->>Calendar: クリックイベント検知
    Calendar->>State: 選択日付を保存<br/>(selectedDate = "2025-01-15")
    activate State
    State-->>Calendar: ステート更新完了
    deactivate State
    Calendar->>UI: 日付ハイライト適用<br/>(背景色変更)
    activate UI
    UI-->>Calendar: ハイライト表示完了
    deactivate UI
    Calendar->>UI: 操作オプション表示<br/>(勤務時間入力/休暇登録ボタン)
    activate UI
    UI-->>User: 選択日付と操作オプション表示
    deactivate UI
    deactivate Calendar
    
    Note over User,UI: 従業員は選択した日付と<br/>利用可能な操作を確認できる
```

### SEQ-UC002-002: カレンダー月切り替え

#### 目的

* 従業員がカレンダーの表示月を前月または次月に切り替える
* 切り替え後の月のカレンダーを正しく表示する

#### 範囲

* **トリガー**: 従業員が前月ボタン（<）または次月ボタン（>）をクリック
* **含むコンポーネント**: メイン画面（SCR-001）のカレンダーコンポーネント、月ナビゲーションボタン
* **除外**: 勤怠データの取得（将来の要件で実装）

#### 前提条件

* メイン画面（SCR-001）が表示されている
* カレンダーが正常にレンダリングされている
* 現在の表示月が確定している（例: 2024年11月）

#### 事後条件

* カレンダーが指定された月（前月または次月）に切り替わる
* 新しい月の年月表示が更新される（例: 「2024年 11月」→「2024年 12月」）
* 新しい月の日付セルが正しく表示される
* 日付選択状態はリセットされる（オプション）

#### 基本フロー

1. 従業員がメイン画面（SCR-001）でカレンダーを閲覧している
2. 従業員が次月ボタン（>）をクリックする
3. フロントエンド（React）がボタンのクリックイベントを検知する
4. 現在の表示月を1ヶ月後に更新する（例: 2024年11月 → 2024年12月）
5. コンポーネントのステート（currentMonth）を更新する
6. UIを再レンダリングし、新しい月のカレンダーを表示する
7. 年月表示を更新する（例: 「2024年 12月」）
8. 従業員が新しい月のカレンダーを確認できる

#### 代替フロー

* **A1: 前月ボタンをクリック** — 表示月を1ヶ月前に更新する（基本フローと同様）
* **A2: 年をまたぐ月切り替え** — 12月→1月、または1月→12月の場合、年も適切に更新する（例: 2024年12月 → 2025年1月）

#### シーケンス図

```mermaid
sequenceDiagram
    actor User as 従業員
    participant NavButton as 月ナビゲーションボタン
    participant Calendar as カレンダーコンポーネント
    participant State as Reactステート管理
    participant UI as UI表示
    
    User->>NavButton: 次月ボタンをクリック<br/>(>)
    activate NavButton
    NavButton->>Calendar: クリックイベント通知
    deactivate NavButton
    activate Calendar
    Calendar->>Calendar: 次月を計算<br/>(2024-11 → 2024-12)
    Calendar->>State: 表示月を更新<br/>(currentMonth = "2024-12")
    activate State
    State-->>Calendar: ステート更新完了
    deactivate State
    Calendar->>UI: カレンダー再レンダリング<br/>(2024年12月の日付表示)
    activate UI
    UI-->>Calendar: レンダリング完了
    deactivate UI
    Calendar->>UI: 年月表示を更新<br/>("2024年 12月")
    activate UI
    UI-->>User: 新しい月のカレンダー表示
    deactivate UI
    deactivate Calendar
    
    Note over User,UI: 従業員は次月のカレンダーを<br/>閲覧できる
```

### SEQ-UC002-003: カレンダー異なる日付選択

#### 目的

* 既に日付が選択されている状態で、従業員が別の日付を選択する
* 以前の選択日付のハイライトを解除し、新しい選択日付をハイライトする
* 操作オプションを新しい日付に対応した内容に更新する

#### 範囲

* **トリガー**: 日付が既に選択されている状態で、従業員が別の日付セルをクリック
* **含むコンポーネント**: メイン画面（SCR-001）のカレンダーコンポーネント
* **除外**: 実際の勤怠データ取得（将来の要件で実装）

#### 前提条件

* メイン画面（SCR-001）が表示されている
* カレンダーが正常にレンダリングされている
* 既に日付が選択されている（例: 2025-01-15）
* 選択日付がハイライト表示されている

#### 事後条件

* 以前の選択日付のハイライトが解除される
* 新しい選択日付がハイライト表示される
* 操作オプションが新しい日付に対応した内容に更新される
* システムの状態として、新しい選択日付が保持される

#### 基本フロー

1. 従業員がメイン画面（SCR-001）でカレンダーを閲覧している
2. 既に日付（例: 2025-01-15）が選択されている状態
3. 従業員が別の日付セル（例: 2025-01-20）をクリックする
4. フロントエンド（React）が日付セルのクリックイベントを検知する
5. 以前の選択日付（2025-01-15）のハイライトを解除する
6. 新しい選択日付（2025-01-20）をコンポーネントのステート（state）に保存する
7. UIを更新し、新しい選択日付セル（2025-01-20）に視覚的なハイライトを適用する
8. 操作オプションを新しい日付に対応した内容に更新する
9. 従業員が新しい選択日付と操作オプションを確認できる

#### 代替フロー

* **A1: 同じ日付を再度クリック** — 選択を解除する（トグル動作）、または何もしない（設計による）
* **A2: 月をまたいで日付を選択** — 月が切り替わり、新しい月の指定日付が選択される

#### シーケンス図

```mermaid

    User->>Calendar: 異なる日付セルをクリック<br/>(例: 2025-01-20)

    Calendar->>State: 新しい選択日付を保存<br/>(selectedDate = "2025-01-20")
    activate State
    State-->>Calendar: ステート更新完了
    deactivate State
    Calendar->>UI: 新しい日付にハイライト適用<br/>("2025-01-20")
    activate UI
    UI-->>Calendar: ハイライト表示完了
    deactivate UI
    Calendar->>UI: 操作オプション更新<br/>(日付 "2025-01-20" 対応)

    UI-->>User: 新しい選択日付と<br/>更新された操作オプション表示
    deactivate UI
```

### SEQ-UC002-004: カレンダー年月選択

#### 目的

* 従業員が年月選択モーダルから表示する年月を直接指定する
* 確定時に該当月のカレンダーを表示し、キャンセル時は表示年月を維持する

#### 範囲

* **トリガー**: 従業員が年月表示ボタンを操作する
* **含むコンポーネント**: メイン画面（SCR-001）のカレンダーコンポーネント、年月選択モーダル（SCR001-8）
* **除外**: 勤怠データの取得（将来の要件で実装）

#### 前提条件

* メイン画面（SCR-001）が表示されている
* カレンダーが正常にレンダリングされている
* 現在の表示年月が確定している

#### 事後条件

* 確定時は指定年月のカレンダーが表示される
* キャンセルまたはEscapeキーで閉じた場合は、表示年月が変更されない
* モーダルを閉じた後、フォーカスが年月表示ボタンに戻る

#### 基本フロー

1. 従業員が年月表示ボタンを操作する
2. フロントエンド（React）が年月選択モーダルを開く
3. 現在表示中の年月を初期値として表示する
4. 従業員が年（1900〜2100年）と月（1〜12月）を選択する
5. 従業員が「確定」を選択する
6. フロントエンドが表示年月のステート（`currentMonth`）を指定年月に更新する
7. UIを再レンダリングし、指定年月のカレンダーを表示してモーダルを閉じる

#### 代替フロー

* **A1: 「キャンセル」を選択** — 表示年月を変更せずモーダルを閉じ、年月表示ボタンへフォーカスを戻す
* **A2: Escapeキーを押す** — A1と同じ動作でモーダルを閉じる

#### シーケンス図

```mermaid
sequenceDiagram
    actor User as 従業員
    participant Trigger as 年月表示ボタン
    participant Dialog as 年月選択モーダル
    participant Calendar as カレンダーコンポーネント
    participant State as Reactステート管理
    participant UI as UI表示

    User->>Trigger: 年月表示を操作
    Trigger->>Dialog: モーダルを開く
    Dialog-->>User: 現在の表示年月を初期値として表示
    User->>Dialog: 年（1900〜2100）と月（1〜12）を選択
    alt 確定
        User->>Dialog: 確定を選択
        Dialog->>State: 表示年月を更新
        State-->>Calendar: currentMonthを指定年月に変更
        Calendar->>UI: 指定年月のカレンダーを表示
        Dialog-->>Trigger: モーダルを閉じてフォーカスを戻す
    else キャンセルまたはEscape
        User->>Dialog: キャンセルまたはEscape
        Dialog-->>Trigger: 表示年月を維持して閉じ、フォーカスを戻す
    end
```
